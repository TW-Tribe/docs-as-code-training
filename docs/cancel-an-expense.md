# Cancel an Expense

Learn how to cancel an expense that has not yet been approved.

## Before you begin

Make sure that:

- The expense belongs to you.
- The expense has not yet been approved.
- You have access to the Expenses feature.

## When can I cancel an expense?

You can cancel an expense while it is in **Draft** or **Submitted** status.
You cannot cancel an expense after it has been approved or rejected.

## Cancel an expense

1. Sign in to ExpenseFlow.
2. Open **Expenses**.
3. Select the expense you want to cancel.
4. Select **More**.
5. Select **Cancel**.
6. Select **Confirm** to cancel the expense.

After you cancel the expense, its status changes to **Cancelled**.

:::warning

An approved expense cannot be cancelled.

:::
