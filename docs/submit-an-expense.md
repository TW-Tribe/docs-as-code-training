# Submit an Expense

Learn how to submit an expense for approval in ExpenseFlow.

## Before you begin

Make sure you have:

- An active ExpenseFlow account
- Access to the Expenses feature
- The receipt or supporting document for the expense

## Create an expense

1. Sign in to ExpenseFlow.
2. Open **Expenses** from the navigation menu.
3. Select **New Expense**.
4. Enter the expense details.
5. Attach the receipt.
6. Select **Submit**.

## Enter expense details

Provide the following information:

| Field | Description |
|---|---|
| Date | Date on which the expense occurred |
| Amount | Total amount of the expense |
| Category | Category assigned to the expense |
| Description | Brief explanation of the expense |

## Submit the expense

After entering all required information:

1. Review the expense details.
2. Confirm that the receipt is attached.
3. Select **Submit**.

The expense is sent to your manager for approval.
